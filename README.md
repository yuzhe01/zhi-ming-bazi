# 知命 2.1 · 具体事情版

公开访问：https://yuzhe01.github.io/zhi-ming-bazi/

按出生信息排四柱，并将事业、收入和关系拆成具体条件情景：会体现成什么事、好在哪里、成立条件、阻力、年度范围和兑现标志。支持在职、求职、经营、在读及关系状态切换；本年主题、大运背景和本命背景分别标注。完整命盘原理可展开阅读，支持报告导出和打印。

这是传统文化取象的现代场景转述，不能确认未来会发生的事件。健康不推断疾病或寿命。

支持安装为 PWA，首次联网缓存后可离线排盘。网站和安装版使用相同代码，各设备独立保存命盘。更新后重新打开网页；已安装版本可能需要联网打开后再刷新一次。

本仓库只发布网站静态文件，不存放访客出生信息、个人命盘或凭证。无需注册，计算在浏览器内完成。

历法依赖 6tail/lunar-javascript，MIT 许可及来源记录在 vendor/ 目录。页面方法说明中保留传统典籍与 GitHub Skills 参考链接。
