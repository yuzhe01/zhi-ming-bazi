# 知命 · 四柱八字详解

公开网站发布文件。页面、脚本与安装版资源由同一套解析引擎生成。

八大报告章节：命盘结构、事业、财与资源、姻缘、健康生活、五年逐年解析、行动路线、白话词典。支持公农历/闰月、子时流派选择、交运日期、大运阶段、完整报告导出和打印。

这是传统术数的文化解读工具，不构成科学预测或医疗诊断。报告列出盘面依据及简化规则；不作必然事件与疾病断言。

## 隐私

出生信息在访客设备内计算。用户主动保存时仅写入当前浏览器 localStorage，不写入本仓库或公共数据库。请自行保管导出的报告。

## 手机安装版

支持 PWA：Android/电脑 Chrome 或 Edge 可从菜单安装；iPhone/iPad Safari 可添加到主屏幕。首次联网缓存后可离线使用。不是原生 APK 或应用商店发行包。
