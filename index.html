ZHI MING · ON YOUR PHONE

把知命，放进手机里。

手机安装版与网站共用同一份排盘和解析引擎。首次联网打开后，可以离线排盘与查看报告。

Android / 电脑

在支持安装的 Chrome 或 Edge 中打开网址，选择“安装应用”。如果没有出现安装按钮，可以从浏览器菜单中安装。

iPhone / iPad

用 Safari 打开网址，点“分享”，选择“添加到主屏幕”，之后可从桌面独立打开。

这是可安装的网页应用（PWA），并非应用商店里的原生 APK / iOS 安装包。每台设备独立保存命盘；不会自动跨设备同步个人信息。

排盘依据与支持范围 ＋

历法采用 6tail/lunar-javascript（MIT），支持 1901–2099 年公历、农历及闰月输入。首版按 UTC+8 排盘，不自动识别历史夏令时；可手动减去 1 小时。年柱按立春、月柱按十二节的实际时刻划分。子时换日可选 00:00 或 23:00。

GitHub Skills 如何用于这个网站 ＋

参考了 jinchenma94/bazi-skill 的信息收集、未知时辰处理与典籍索引，以及 gaoxin492/bazi-skill 的结构化命盘、排盘与解读分离、本地保存思路。本站独立实现网页和解读规则，未运行第三方 Skill 脚本，未将其完整规则模型移植进来。

解读模型与数据保存 ＋

解读由浏览器中的固定规则生成，不调用大模型。详细报告逐项列出月支本气、根气、月令藏干透出、十神位置及六合、六冲、六害、六破、天干五合、齐字三合三会。格局组合仅作有条件的结构线索；没有按分日司令、全局合化或全部日干月令调候表作最终格局定论。大运按交运日期分段，流年以立春为界。出生信息不会提交给本站服务器；点击“保存命盘”后，才存入当前浏览器的本地存储，可随时删除。导出的文件包含出生信息，请自行保管。

传统文化的适用边界 ＋

八字是传统术数文化，不是现代科学预测方法。本站不预测具体事件、疾病或寿命，不以八字替代医疗、财务、职业或婚姻决策。健康页面仅含一般生活提示。
